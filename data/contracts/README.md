# Evaluation contracts

The `cuad-*` contracts are derived from **CUAD v1**, © The Atticus Project, and are used under the
Creative Commons Attribution 4.0 International licence (CC-BY-4.0). CUAD contains contracts filed
publicly with the U.S. Securities and Exchange Commission. Canonical plain text and generated DOCX
copies are committed only for reproducible evaluation.

Source: The Atticus Project, *Contract Understanding Atticus Dataset (CUAD)*,
<https://github.com/TheAtticusProject/cuad>.

The `synth-*` contracts are synthetic and contain no private contract data.
